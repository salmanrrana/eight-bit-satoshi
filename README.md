# 8-Bit Satoshi

Playable static canvas game. No install step is required.

## Start

```bash
npm start
```

Open:

```text
http://127.0.0.1:5000/
```

That runs in the current terminal. Stop it with `Ctrl+C`.

## Start In Background

```bash
npm run start:service
```

Stop the background server:

```bash
npm stop
```

## Check

```bash
npm run check
```
